# Theme Store

<Badge text="Online theme index" type="tip" /> <Badge text="Must download before import" type="warning" />

The theme store browses, downloads and applies `.fpt` themes. You can search by name, author and description, and filter by author, official or third-party source, and phone or tablet type.

## Built-in Mode

Downloading, progress display, pausing and resuming all happen inside the Manager, after which the same theme import confirmation dialog opens. Theme files are stored in the Manager's private directory and can be applied again or deleted from "My themes".

## Compatibility Mode

The theme download link is handed to the system browser. After saving, open the `.fpt` with FinaSU from a file manager, or select the file from "Settings → Appearance → Wallpaper → Import theme package". This mode suits devices where the built-in download or the file import flow is unstable.

## Applying a Theme

A finished download does not mean the theme is applied. Only after you select a theme and confirm applying it does the Manager run the transactional import of resources, settings and language. A theme may contain wallpaper, font, layout, navigation icons, music and other appearance settings, so check the source and the preview before applying.

If applying fails, check the file integrity, the resources the theme requires and the import warnings. The store mode is changed under "Settings → Appearance → Theme store mode" and never applies an already downloaded theme automatically.

For the full flow, see [Theme Preview & Usage](/en/theme/theme-use/).
