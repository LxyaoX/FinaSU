# Module Cards

## Cards

- **Show module details**: shows the version, author and description on the module card.
- **Collapse module cards**: tucks the action buttons away until the card is expanded.
- **Joined cards**: joins the cards in the same group into a single block.
- **Button style**: chooses how the card action buttons are presented.
- **Maximum description lines**: descriptions longer than the limit collapse automatically; tap the card to expand.

Group ordering distinguishes Metamodules, Zygisk, LSPosed, modules with a WebUI and modules with actions.
