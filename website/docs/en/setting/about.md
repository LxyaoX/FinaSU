# About

<Badge text="Home screen shortcut" type="info" /> <Badge text="Check here first when reporting" type="tip" />

The "About" page on the Settings home screen shows only the Manager name, the Manager version and project links. It is not a complete runtime status panel.

## Page Contents

- **App name**: the name the current Manager uses.
- **Manager version**: the `versionName` of the current APK.
- **GitHub**: opens the project source and releases page.
- **Telegram**: opens the project channel.

::: info The About page does not show the driver version

The kernel build, runtime mode, UAPI and driver state belong on the home screen status card or another diagnostics entry. When reporting a problem, do not provide only the Manager version from the About page.

:::

## What to Include When Reporting

It helps to record all of the following:

- The actual runtime mode shown on the home screen: LKM, Built-In or Jailbreak mode.
- The kernel build version, UAPI and KMI.
- The device model, Android version and security patch level.
- Repeatable steps, expected result and actual result.
- The log file exported by "Send logs".

For the full checklist, see [Diagnostics & Feedback](/en/setting/diagnostics/).
