# Navigation

## Navigation Mode

- **Automatic classic navigation bar**: switches between bottom navigation and side navigation depending on screen size.
- **Always bottom navigation bar**: suits phones.
- **Always side navigation bar**: suits tablets or landscape.
- **Floating bottom navigation bar**: uses a separate capsule style, see [Floating Navigation Bar](/en/setting/floating-bar/).

## Pages and Badges

You can hide the plugins, Superuser and modules entries, and you can show navigation badges. The Superuser badge shows the number of authorized apps, the plugin badge shows the number of enabled plugins, and the modules badge shows the number of enabled modules; when module updates are available, the update count is shown first. Hiding an entry does not delete data.

## Gestures and Icons

- **Predictive back gesture**: asks the system for the predictive back animation.
- **Custom bottom navigation icons**: choose a local image for each of the home, plugins, Superuser, modules and Settings entries.
- **Layout variant**: choose a classic or M3E top bar for the plugins, Superuser and modules pages.

Navigation layout changes may require re-entering the page before they fully take effect. Restoring the default wallpaper also clears the custom navigation icons.
