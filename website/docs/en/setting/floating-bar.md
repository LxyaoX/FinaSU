# Floating Navigation Bar

The floating navigation bar collects the bottom entries into a floating capsule. These options appear only when the navigation mode is set to "Floating bottom navigation bar".

## Styles

- **Standard**: a fixed-width floating capsule.
- **Drawer**: a more compact expandable style.
- **Compact rounded**: reduces the capsule size and corner spacing.

## Frosted Glass

Android 13 and later can enable live blur. The adjustable items include:

- Blur strength
- Background transparency
- Highlight strength
- Specular reflection
- Inner glow
- Glass border

On older systems that do not support live blur, turn frosted glass off and use a plain background.

## Auto-Hide

- **Auto-hide**: hides after 3 seconds without interaction.
- **Slide to hide**: swipe down to hide, swipe up to restore.

Hiding is a UI behavior only; it does not affect page state or background tasks.
