# 模块卡片

## 卡片

- **显示模块详情**：在模块卡片上显示版本、作者与描述。
- **折叠模块卡片**：在卡片展开前收起操作按钮。
- **拼接卡片**：把同一分组内的卡片连成一段。
- **按钮样式**：选择卡片操作按钮的呈现方式。
- **描述最大行数**：超过行数的介绍自动折叠，点击卡片展开。

分组排序会区分元模块、Zygisk、LSPosed、带 WebUI 和带操作的模块。
