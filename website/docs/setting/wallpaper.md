# 壁纸

壁纸页面为管理器设置全局或按页面区分的背景，并控制壁纸与表面之间的层次。

## 背景

- **启用壁纸**：在界面底层显示图片。
- **多页面背景**：分别为首页、插件、超级用户、模块和设置选择图片。
- 单页可以选择、更换或移除图片。

### 视频背景

开启视频背景后，视频会替代静态壁纸。可以选择或清除视频文件，并调整视频音量。

视频模式下仍可设置遮罩；“表面不透明度”“模糊”和“从壁纸取色”只针对静态图片，会暂时隐藏。视频会持续解码播放，低性能设备可能更耗电。

## 显示

- **表面不透明度**：卡片与页面表面遮挡背景的程度。
- **模糊**：设置背景图片的模糊半径。
- **遮罩**：压暗背景以保证文字对比度。
- **日夜遮罩分离**：为浅色与深色模式分别设置遮罩。
- **卡片背景 / 聚焦卡片背景**：让特定卡片使用壁纸层。
- **从壁纸取色**：使用当前背景生成强调色。

## 工作卡片

首页最上方的工作卡有自己的一块壁纸表面，和页面背景互不影响：

- **图片**：只给工作卡选一张图。
- **启用工作卡背景**：关闭时不绘制图片，卡片回到纯色。
- **不透明度**：图片自身的不透明度，可切换为日夜两组数值。
- **暗度**：压暗图片，保证“工作中”这几个大字仍然可读，同样可以日夜分开。
- **隐藏图标 / 隐藏文字 / 隐藏运行方式**：分别去掉角上的对勾、标题下的版本号和上沿的运行方式标记。

统计卡与系统信息卡跟随页面背景，不能单独选图。
