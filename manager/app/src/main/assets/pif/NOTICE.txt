PlayIntegrityFix
================

The archive in this directory (playintegrityfix-arm64.zip) is a repack of the
official module release:

    Repository:  https://github.com/KOWX712/PlayIntegrityFix
    Release:     v4.9-inject-s (2026-10-15)
    Upstream:    PlayIntegrityFix_v4.9-inject-s.zip
    sha256:      bc7a9d92638a6bd90a41b70d3aaf86bc549dd8d3a1e5e901b315a6c425852697

This project is distributed under the GNU General Public License v3.0. See the
LICENSE in the upstream repository; the module's own scripts are unmodified.

What the repack removes, and why:

    webroot/**            1.1 MB of WebUI. This manager draws the same controls
                          in its own settings page, so shipping a second UI
                          only to hide it would double the payload.
    zygisk/x86_64.so      this project ships arm64-v8a only.
    zygisk/armeabi-v7a.so same.
    META-INF/**           the module is installed by the manager, never flashed.

Everything else - module.prop, pif.prop, post-fs-data.sh, service.sh,
common_func.sh, autopif.sh, autopif_ota.sh, security_patch.sh, uninstall.sh,
customize.sh, action.sh, classes.dex and zygisk/arm64-v8a.so - is byte for byte
what upstream published.

The module is installed to /data/adb/modules/playintegrityfix because that is
where a Zygisk implementation looks for `zygisk/<abi>.so`; unlike the bundled
TEESimulator runtime it cannot live outside the module directory.
